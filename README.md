# FiliArrochada/.github

The FiliArrochada organisation's special `.github` repository. On GitHub it must be named exactly
`.github`; locally it is checked out as `FiliArrochada.github/`.

| File | What GitHub does with it |
|---|---|
| `FUNDING.yml` | The Sponsor button on every org repo that has no `.github/FUNDING.yml` of its own |
| `profile/README.md` | The organisation's public profile at `github.com/FiliArrochada` |

This README itself is not shown on the profile.

## Before the first push

- [ ] GitHub Sponsors approved (`github: [FiliArrochada]` only works then)
- [ ] Push `FiliArrochada.github.io` too: `FUNDING.yml` and the profile link to its `/support/` page
- [ ] Check the thanks.dev link GitHub generates from `thanks_dev: e/gh/filiarrochada`

Repos owned by other accounts don't inherit `FUNDING.yml` and need their own copy in `.github/`.

The support page itself lives in `FiliArrochada.github.io/`. The full plan, with the fee comparison and sources, is in the workspace's
`.guidelines/fili-payment-options.md`.
